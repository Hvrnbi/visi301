# Projet VISI301 - Jeu avec pygame

Dans notre super jeu dont le nom est encore à définir, vous incarnez un couple poule / coq qui doit s'échapper de son poulailler.

Nourissez-vous, faites des poussins, protégez les des renards et, le moment venu, encerclez le fermier pour lui voler la clé !

### Ce jeu est en développement actif, certaines fonctionnalités ne sont pas encore prêtes.
